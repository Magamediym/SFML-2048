# 🎮 2048 на C++ и SFML

Моя реализация популярной игры 2048 на языке C++ с использованием графической библиотеки SFML.

## 🛠 Технологии
* C++ (стандарт C++17)
* SFML (графика, окна, события)
* Visual Studio

## 🕹 Управление
* **W** — сдвиг вверх
* **A** — сдвиг влево
* **S** — сдвиг вниз
* **D** — сдвиг вправо

## ✨ Особенности
* Полноценная графическая реализация.
* Плавное управление с клавиатуры.
* Система подсчета очков.
* Проверка условий победы (2048) и поражения.

## 🚀 Как запустить
1. Скачайте репозиторий.
2. Откройте файл решения (.slnx) в Visual Studio.
3. Убедитесь, что в настройках проекта подключена библиотека SFML.
4. Соберите проект (Build) и запустите (Run).
